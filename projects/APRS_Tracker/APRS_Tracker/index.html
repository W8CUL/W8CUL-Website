APRS Tracker

The W8CUL APRS Tracker is an open-source Terminal Node Controller (TNC) kit that transforms an inexpensive Baofeng handheld radio into a fully functional APRS tracker.

Designed by club members for high-altitude balloon tracking, this kit has proven reliable at altitudes exceeding 100,000 feet and temperatures below -60°C. Now available as a build-it-yourself project for club members and the amateur radio community.

Key Features

Extreme Temperature

Tested to -60°C. Perfect for high-altitude balloon missions and cold-weather operations.

Low Power

Consumes only 35mA in standby. Run for days on a small battery pack.

Open Source

Full schematics, PCB files, and firmware available on GitHub under MIT license.

GPS Telemetry

Transmits position, altitude, speed, temperature, and battery voltage.

Baofeng Compatible

Works with UV-5R and similar radios. Just plug in the audio cable and go.

Easy Assembly

Through-hole components only. Great first soldering project!

Assembly Instructions

Follow these steps to build your W8CUL APRS Tracker. Total assembly time: 1-2 hours.

Required Tools:

  • Soldering iron (temperature controlled, 350°C)
  • Solder (lead-free recommended, 0.8mm)
  • Flush cutters
  • Multimeter
  • Tweezers
  • Safety glasses

Nice to Have:

  • PCB holder / helping hands
  • Solder wick or solder sucker
  • Magnifying lamp
  • USB-to-FTDI programmer
  • Oscilloscope (for debugging)
Verify all components against the BOM before starting. Check for damaged or missing parts.

Start with the lowest-profile components and work up. This makes soldering easier.

  1. Resistors (R1-R5): Bend leads, insert, solder, and trim. Orientation doesn't matter.
  2. Ceramic Capacitors (C1-C5): No polarity. Insert and solder.
  3. Crystal (Y1): Insert the 8MHz crystal. Keep it close to the board.
  4. IC Socket (U1): Note the notch orientation! Solder corner pins first, then all pins.
  5. Trimmer Potentiometer (RV1): Push flush to board and solder.

Tip: Solder one pin first, check alignment, then complete the rest.

  1. Electrolytic Capacitor (C6): Watch polarity! Negative stripe goes to the marked side.
  2. Voltage Regulator (U2): Flat side matches silkscreen. Don't overheat!
  3. LEDs (D1, D2): Long leg is positive. Match to + marking on board.
  4. FTDI Header (J1): 6-pin header for programming.
  5. Audio Jack (J2): May need to file mounting tabs slightly.

  1. Solder the 4-pin header to the GPS module if not pre-installed.
  2. Connect GPS to main board: VCC→3.3V, GND→GND, TX→RX, RX→TX.
  3. The ceramic antenna should face up and have a clear view of the sky.
  4. For high-altitude use, configure the GPS for "flight mode" to work above 18km.
The GPS needs to be configured for flight mode using u-center software. Instructions are in the GitHub repository.

  1. Insert the ATmega328P into the socket. Match the notch to the silkscreen!
  2. Connect a USB-FTDI adapter to the programming header.
  3. Open Arduino IDE and select "Arduino Pro Mini 3.3V 8MHz".
  4. Download the firmware from GitHub (replace XX with repo URL if available).
  5. Edit config.h to set your callsign, SSID, and beacon interval.
  6. Upload the sketch. The green LED should blink on successful programming.
// config.h - Example configuration
#define CALLSIGN "W8CUL"
#define SSID 11
#define BEACON_INTERVAL 60  // seconds
#define SYMBOL '/'  // APRS symbol
#define SYMBOL_TABLE 'O'  // Balloon

  1. Power Test: Connect battery. Check 3.3V at regulator output.
  2. GPS Lock: Take outside. Red LED should flash when GPS has lock (may take 5 min on first use).
  3. Audio Level: Connect to radio and monitor on another receiver. Adjust trimmer for clean audio.
  4. APRS Test: Verify packets are decoded correctly on aprs.fi or a local iGate.
  5. Range Test: Walk around campus and verify coverage.
Success! If your packets appear on aprs.fi, your tracker is working correctly.
